Project Overview

This project is a short visual novel created with p5.js. The main theme of the game is a post-apocalyptic future caused by global warming and human irresponsibility. Through the story, characters, backgrounds, music and dialogues, I wanted to show how the choices people make today can have serious consequences in the future.


Idea

The main idea of the project is to reflect on environmental responsibility. I wanted to create a story about the future that could happen if society continues to ignore climate problems. The game is not only about a fantasy apocalypse, but also about real fears connected to the modern world. I chose the format of a visual novel because it allowed me to focus on dialogue and emotions instead of complicated gameplay. I wanted the player to pay attention to the characters and their stories. 


Creative Process

At the beginning of the project, I developed the main concept and wrote the story. I planned the structure of the visual novel, the main events and the possible endings. After that, I wrote the dialogues for each character and described their visual design in text form. The next stage was character design. I drew the characters in Procreate, using a semi-realistic style. I wanted the characters to look humanoid, but also to have visual features connected to animals or mutations. Their designs were created to match the post-apocalyptic settings.

After finishing the first character drawings, I started working on the code. The first version of the project was very rough. It had no detailed backgrounds, some scenes were unfinished, and there were technical problems such as bugs and errors. During the rest of the month, I focused on improving the code and making the game more stable. I added character sprites, dialogue boxes, sounds, ambient music, background images, scene changes and two endings.


Visual Style

The visual style of the project is dark. I wanted the game to feel sad and uncomfortable. The characters are the most important visual part of the project, so I spent a lot of my time drawing and improving them. The world of the game is inspired by burned landscapes, abandoned places, polluted areas and damaged nature. The colours are mostly cold, dark or dusty, these colours help create the atmosphere. Unfortunately, I left the background for the last stage of the project. Because of this, I did not have enough time to draw the laboratory background in full detail. However, I still tried to make the visual suitable for the story.


Technical Process

The game was coded in JavaScript using the p5.js library. The code includes several important systems:

- loading images and sounds;
- displaying character sprites;
- switching between scenes;
- showing dialogues;
- handling player choices;
- changing backgrounds;
- playing music and sound effects;
- showing ending screens.

A lot of work was spent on improving the user experience. I wanted the dialogue system to be readable and comfortable. I also adjusted the character sizes and positions so that the main character and other characters looked balanced on screen.

Sound was also an important part of the project. Background music and ambient sounds help create atmosphere and make each scene feel more alive. For example, different sounds are used for the forest, swamp, station and events.


Challenges

The biggest challenge was working by myself combining art, writing and coding in one project. Each part needed a lot of time, and changing one element often created new problems in another part. For example, when I changed character sizes, I also had to adjust their positions and make sure they did not look odd on the screen. Another challenge was fixing bugs. At some points, the game did not move correctly to the next scene, or the endings did not appear in the way I wanted. I had to reorganise parts of the code to make the structure clearer. Time management was also difficult. I spent a lot of time improving the characters and the code, so I did not have enough time to fully finish all the backgrounds even though ive got a 2 days extension.
